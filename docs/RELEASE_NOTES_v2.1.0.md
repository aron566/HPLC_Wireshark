# 发版说明 v2.1.0

自 v2.0.1 以来共合入 **282 笔提交**（fix 153 / test 34 / ci 17 / refactor 10 / docs 10 / chore 6 / feat 5）。本版无破坏性配置变更，旧抓包与块文件可直接打开（存储块版本仍为 20，未迁移）。

## 升级须知

- `update.json` 的 `latest-version` 已抬到 `2.1.0`，内置更新器会提示升级。
- 无配置项删除或改名；`config.ini` 仍可直接沿用。

## 协议解析

- **4B 单跳帧头 ICV 校验**：国网 HDC2.0/HDC1.0 的 4 字节简头分支此前跳过了尾部完整性校验值，现与标准头路径口径一致（`MSDU CRC32` 节点同源、末尾统一 `msdu_crc_gate`）。
- **CRC 三态统一**：信标载荷 `BeaconCRC32` / `BPCS` 与 `MSDU CRC32` 共用三态判定（OK / FAIL / N/A）；**MSDU CRC 通过即允许拓扑学习，压过 PB 块 CRC 失败**；红行判据收敛为单一 `frame_crc_red()`。
- **反转义宽松化**：帧尾带 ASCII 调试日志（含未转义 `0x3D`）的现场帧不再被整帧丢弃；`0x3E` 帧定界仍严格。
- **南网表9 应用层释义**：按「端口号 + BID」联合判定业务类型与方向（如 `应用层报文 (BID=0x03 站点间通信 ↑)`），单一实现 `nw_app_bid.h`。
- 截断帧一律「保留并标注」，不再静默丢弃：字段表尾部截断处追加 `(字段截断)/期望 n 字节,实际 m 字节` 标记节点。

## 拓扑

- 新增异常检测：**同 MAC 多 TEI、同 TEI 多 MAC、重启计数振荡、双链路计数不一致**；重启计数「首变不计」，回绕做专门抑制。
- **asof MAC 回退改为「唯一才回退」**：同一 NID 下某 TEI 只能唯一对应一个 MAC 时才回退填充，多义一律显示「未知」。此前按 `QHash` 迭代取首个，同一二进制连跑会在不同 MAC 间摇摆。
- 路由变更表在 asof 缺映射时回退实时 `mac_to_tei`，修补「信标/逐帧学到的 TEI→MAC 从不进 asof」导致的整列为「未知」。

## 插件体系

- 心跳可配置（间隔 / 空闲 / 超时），空闲自动退避；心跳超时禁用卡死宿主。
- 修复宿主退出/崩溃时 `QProcess` 在自身 `finished`/`errorOccurred` 信号里被同步 `delete` 的**释放后使用**。
- Lua 沙箱：拒绝原因对脚本不可区分（`{Ok, Denied}`），堵住沙箱外文件存在性探测；看门狗打断不再被误报成脚本超时。
- 插件市场：提权部署副本归 root、README 链接禁止自行导航、符号链接一律拒装。

## 加固（L1–L9）

截断多站 SOF 越界守卫 · GW2022 `RfdlChCombo` 更名消除 ODR · 字段表截断显式标注 · GW Lua dissector 去 `bit.rshift` · Lua 入口改走 `lua_pcall` · 盘块 `pb_heads`/`pb_crc_oks` 读侧语义上限 · 过滤暂存与条目总数上限 · 下载 `file://` 仅调试构建放行 · 插件心跳配置化。

## 存储与更新

- 块序列化读侧加固：按剩余字节校验元素数，超限置 `ReadCorruptData` 让整块失败 —— **损坏数据整体拒绝且不把流读错位**。
- 离线安装包改为单次解压（此前同一文件被解压两次，第一次结果被丢弃）。
- 下载失败全链路上报：网络错误 / 超大下载 / 重命名失败都会经 `Updater` → `SimpleUpdater` 传到主窗口（只记日志与状态栏留痕，不重复弹框）。

## 质量门禁

- **libFuzzer 接入 CI**：覆盖 PB 组装、`get_bits` 越界坐标、`add_fields` 截断三个原语层，`-max_total_time=30` 有界（实测 30 s 内 137 万次执行，覆盖率 482 → 668）。
- ASan/UBSan 探针（插件宿主 UAF、GetBits 等）、TSan 探针、探针套件失败时自动上传日志 artifact。
- CI 探针套件新增：4B 简头 ICV、信标 CRC、asof 唯一性、TEI-MAC 学习回归等门禁。

## 已知说明

- Linux 侧部分探针（插件 IPC / 图形夹具）依赖 POSIX 信号语义，仅在该平台运行；Windows 本地跑会出现平台语义差异导致的失败，属预期。
- 内置更新器不校验安装包 SHA-256；`SHA256SUMS.txt` 随 Release 发布，供下载页手动核对。
