# TOPO 邻居明细评分（双向通讯画像 + 可靠度）

本文档定义拓扑「邻居明细」表的字段方向语义、可靠度评分公式与排序规则。
实现位置：`src/topo/topo_window.cpp`（邻居明细 QTableView）、`src/topo/topo_state.*`、
`src/common/bplcframe.h`（TopoEvent 采集字段）、四协议 MSDU 解析器（RFDL 信道信息采集）。

## 一、方向定义

邻居明细表以「本 STA（下文记 `me`）」视角展示，上行/下行以 **发现列表报文的发送方** 为准：

| 名称 | 方向 | 数据来源（发现列表报文） | 代码表达 |
|---|---|---|---|
| 上行成功率 | 邻居 → 我 | 我发出的发现列表里、关于该邻居的接收率 | `neighbor_rates[me][nb]` |
| 下行成功率 | 我 → 邻居 | 邻居发出的发现列表里、关于我的接收率 | `neighbor_rates[nb][me]` |
| 我报它次数 | — | 我发出的发现列表里出现该邻居的累计次数 | `neighbor_counts[me][nb]` |
| 它报我次数 | — | 邻居发出的发现列表里出现我的累计次数 | `neighbor_counts[nb][me]` |

> 关键约定：`neighbor_rates[上报方 STA][邻居] = 接收率%`，方向 = 「邻居 → 上报方」。
> 因此上行成功率取 `[me][nb]`（我上报的、邻居对我的接收），下行取 `[nb][me]`（邻居上报的、我对邻居的接收）。

## 二、可靠度评分公式

评分按节点接入方式分「无线」与「载波」两套（`TopoNode.is_rf` 区分）。

### 无线（RFDL 来源，接收率驱动）

```
up   = 上行成功率%（缺失记 0）
down = 下行成功率%（缺失记 0）
双向完整 → base = (up + down) / 2
仅单向   → base = 该方向 × 0.6                 // 单向打折系数 0.6
活跃度   = min(1, (counts[me][nb] + counts[nb][me]) / 20) * 100
信号归一 = clamp((rssi_dbm + 110) / 110, 0, 1) * 100   // -110dBm→0, 0dBm→100
R = 0.50·base + 0.30·活跃度 + 0.20·信号归一            // 结果四舍五入取整
```

- 「双向」= 上行、下行接收率**都存在**（6、7 列均非 `—`）。
- 「仅单向」= 上行、下行**恰好一个存在**。

### 载波（发现列表次数驱动，无成功率）

```
对称性 = 双向 ? 100 : (单向 ? 50 : 0)
活跃度 = min(1, (counts[me][nb] + counts[nb][me]) / 20) * 100
R = 0.60·对称性 + 0.40·活跃度
```

- 「双向」= 我报它次数、它报我次数**都 > 0**（8、9 列均非 `—`）。
- 「单向」= 两者**恰好一个 > 0**。

### 取值理由

| 参数 | 值 | 理由 |
|---|---|---|
| 单向打折系数 | 0.6 | 仅单向时无法交叉印证，base 打折为单方向值的 60% |
| 活跃度封顶 | 20 次 | 累计发现 20 次视为「高活跃」，再多次不再加分（饱和） |
| 信号归一范围 | 110 dB | 无线 RSSI 量程 -110~0 dBm 线性映射到 0~100 |
| 无线权重 | 0.50/0.30/0.20 | 成功率为主（双向质量）、活跃度为辅、信号强度参考 |
| 载波权重 | 0.60/0.40 | 无成功率，以对称性（双向互见）为主、活跃度为辅 |

## 三、排序规则（三级，降序）

1. 可靠度 R（降序）
2. 发现列表数总和 `counts[me][nb] + counts[nb][me]`（降序）
3. 信号强度 `rssi_dbm`（降序）

## 四、算例

| 邻居 | 上行/下行成功率 | 我报+它报次数 | RSSI | 链路 | 计算 | R |
|---|---|---|---|---|---|---|
| A | 96 / 88 | 12 + 10 | -55 | 无线 | base=92, 活跃度=100, 信号归一=50 → 0.5·92+0.3·100+0.2·50 | **86** |
| B | 95 / — | 8 + 0 | -50 | 无线 | base=95·0.6=57, 活跃度=40, 信号归一=55 → 0.5·57+0.3·40+0.2·55 | **52** |
| C | 40 / 45 | 15 + 14 | -85 | 无线 | base=42.5, 活跃度=100, 信号归一=23 → 0.5·42.5+0.3·100+0.2·23 | **56** |

排序：**A > C > B**（R 86 > 56 > 52）。

> 信号归一先四舍五入到整数再参与加权（B 的 -50 → 55、C 的 -85 → 23），R 最后四舍五入取整。

## 六、实现要点

- **采集**：RFDL 信道信息 IE（非位图版/位图版）在渲染 `UpRate`/`SNR` 字段时顺手采集
  `TopoEvent.neighbor_rates`（`QVector<QPair<quint16,quint8>>`）与
  `TopoEvent.neighbor_snrs`（`QVector<QPair<quint16,qint16>>`），不改渲染。
- **落地**：单跳帧 `topo_event.kind == Other`（不触发 `apply()`），其信道信息由
  `TopoState::apply_channel_info(reporter_tei, e)` 单独落地；`reporter_tei` 取帧 FCH
  `SrcTEI`（单跳无中继，源=发送方）。
- **键控**：`neighbor_rates[reporter][neighbor]` 与 `neighbor_counts[reporter][neighbor]`
  均按上报方 STA 键控，方向语义见第一节。
