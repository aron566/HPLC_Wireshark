## 1. 总体结论（TL;DR）

1. **低速率无线物联链路层（旧 ch6 ↔ 新 ch6）原样保留**：60+ 张表逐字段一致（PHR/MAC帧头/控制帧/数据帧、13种无线MAC控制帧、BPLC MAC帧扩展、信道划分表、状态切换表、全部服务原语）。仅 2 处非实质差异：版本号取值0定义"本标准"→"本文件"（措辞）；信道划分表正文旧版脱漏"共 个"新版补全"共10个/共20个"（新 L4931）。
2. **⚠️ 新·SPLC 文档内部不一致**：新 ch5 表7 MAC长帧头为 SPLC 新格式（+短网络标识高位 byte0 bit3、+发送序号 12bit），但新 ch6 表241 BPLC MAC长帧头（新 L4837）与旧·无线接入表37（旧 L1206）**逐字段相同**（byte0 bit3-7+byte1 共13bit保留、SNID 4bit、无发送序号）。原因：新 ch6 概述（新 L4348）声明"BPLC部分链路层机制遵循《…低压电力线宽带载波通信规约第5部分：数据链路层通信协议》"，即 ch6 沿用上一代 BPLC 规约帧头而非本文件 ch5。**混合实现必须按（章节上下文/链路类型×标准版本号）分派 MAC 长帧头解析**，建议向编制方确认两章帧头适用关系。
3. **高速率无线链路层（旧 ch8 ↔ 新 ch5）三条系统性变更主线**：
   - **SNID 4bit→5bit 分散扩展**：短网络标识拆为"高位+低位"，高位注入 10+ 处帧结构（MAC长/短帧头 byte0 bit3；MPDU FC byte0 bit4-7 改"低位"；信标FC可变域 byte12 bit1；BPLC SOF可变域 byte5 bit0；SACK可变域 byte4 bit0；网间协调 byte12 bit0；信标载荷 byte0 bit7；无线信标/SOF可变域 byte12 bit0；无线SACK可变域 byte1 bit4）；邻居网络比特图扩为 31bit 覆盖 SNID1-31（新 L804）；服务原语 SNID 取值 1-15→1-31（表197/198/201）；条款依据新 L428/L3091/L3123。**混网缓解条款**：新附录A.1(3)（L5519）"CCO本网络内有BPLC站点，或邻居网络为BPLC网络时，短网络标识应使用1-15范围内的值"——5bit 扩展仅纯 SPLC 网络生效。
   - **SPLC 新机制注入**：标准版本号 1=本标准版本号→1=BPLC版本、**+2=SPLC版本**（值0两版均"保留"未变）；SOF可变域拆分为 BPLC SOF 与 **SPLC SOF**（单站点数据帧/MIMO训练帧/Bitloading训练帧/OFDMA帧 + eFC 三表，全新）；SACK 新增 SNR类型(2bit)+SNR评估信息(30bit)+扩展帧类型值3=Bitloading扩展帧（6种子格式表34-40）；物理块头新增聚合标志(byte2 bit0)+级联头(表48)+16字节物理块(表49)+DL-OFDMA SACK报文内容(表50)；SPLC 物理块体 8/64/128/256/512 字节（BPLC 为 128/512）。
   - **管理消息与字段扩容**：新增 6 种报文 **0x0080-0x0085**（Bitloading训练结果更新请求/确认、RU_SNR信息告知、站点TEI列表请求/回复、扩展网络冲突上报；旧版管理消息止于 0x0070，6个名称+码值 grep 0命中）；关联请求 +扩展特性标识(byte21)+PLC能力指示(byte62 2bit)+通道数(byte62 1bit)；发现列表 +PLC能力指示/通道数(byte12)+与代理的RU_SNR评估信息(byte37-40)；离线原因 +0x5/0x6（第三方设备认证失败/超时）；载波频段 2bit→3bit 且取值表 3值→8值（+3=0.781~11.963、+4=0.781~5.615、5/6/7=保留）；应用报文分类 +IP报言行（MSDU类型0x80）且网络管理子层 LID 0-255→0（收窄）。
4. **新增机制章节 8 个**（旧版关键词 MIMO/分散信标/报文聚合/Bitloading/OFDMA/点对点访问/第三方设备/信道评估/集中信标 全部 0 命中）：MIMO站点时隙管理、集中/分散信标机制、PLC信道评估、报文聚合、Bitloading训练、OFDMA调度（DL/UL）、点对点访问机制、第三方设备组网。新增附录 A（SPLC组网建议）/C（CSMA退避量化表）/D（频段兼容性说明）。
5. **移除内容**：218 对表中**无一字段被彻底删除**（所有初判"删除"经核实均为拆表/rowspan/单位假象或改名保留）；整章移出 1 项（应用层→第5部分）。
