## 二、本轮一并记录的方法论要点

1. **双源互证也要核别人的结论，不能预设某版有缺陷**（@code-review-bot 修正我原「一律用基线件」的前提）。
2. **rowspan 表必须先展开继承格再判单元格数**（M7 判据）。
3. **双源互证 + 冲突时以矢量 PDF 终裁**（400dpi 像素）。
4. **「缺失」先查 `git log --all -- <path>` 与 `.gitignore`**，确认是「漏了」还是「被决定排除」。
5. **PDF 文本流不表达合并单元格** → 涉及合并格的表，文本流输出不能用于判定字节归属。
6. **零值占位既掩盖字节序错误、又让文档与实际字节脱节** → 造帧一律用可区分大小端的值 + 运行时双断言。
7. **核对入库状态时，「缺失」先查历史**（同上第 4 条）。
