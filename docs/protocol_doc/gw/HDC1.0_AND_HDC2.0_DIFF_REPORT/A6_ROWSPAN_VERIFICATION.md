### 2.2 「无 rowspan 的 2 处」的真实归属 —— **属正常表风格，不是缺陷**

字面统计（与移交描述的**数字完全一致**）：

| 转件 | `<td>7</td><td>0-3</td>`（无 rs） | `<td rowspan="2">7</td><td>0-3</td>` |
|---|---|---|
| HDC2.0 基线 260823_203222 | 2 | 4 |
| HDC2.0 新转件 261023_152707 | 2 | 4 |

但那 2 处落在**另外两张表**，且其结构本就如此：

```
新转件 L486 : <td rowspan="2">站点3 目的 TEI</td><td>6</td><td>0-7</td>…</tr><tr><td>7</td><td>0-3</td>
新转件 L796 : <td rowspan="2">站点 TEI1</td>    <td>6</td><td>0-7</td>…</tr><tr><td>7</td><td>0-3</td>
```

**这两张表的「字节号」列是逐行书写的**（上行写 `6`、续行写 `7`），而 **rowspan 落在「字段名 / 字段大小 / 含义」三列**上。
→ 续行写 `<td>7</td>` 是**正确的**；若反而不写字节号，才是缺陷。
→ M7 检测器对这两处**不命中**（它们的续行**有**继承格）。
